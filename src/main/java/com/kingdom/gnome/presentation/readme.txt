Этот слой отвечает за общение с внешним миром (пользователем или другим приложением).
Он принимает запросы и отдает ответы, но сам ничего не вычисляет — всю тяжелую работу он делегирует Бизнес-слою.

Если пишем бэкенд: REST-контроллеры, обработчики HTTP-запросов (например, Spring Controllers).
Если пишем десктоп: Окна, кнопки, обработчики нажатий (JavaFX, Swing).
Если пишем консоль: Классы, которые делают Scanner.nextLine() и System.out.println().
