происходят вычисления и проверки.

Сервисные классы (например, OrderService, UserService).

Правило слоя: Сервисы обращаются к слою Data, чтобы получить или сохранить данные,
но они не должны знать, какая именно там база данных (PostgreSQL, файл или просто массив в памяти).
Они работают через интерфейсы.
